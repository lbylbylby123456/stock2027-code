# Data directory

Place processed split files in this directory or update the paths in `src/run_recat.py`.

Expected filenames by default:

- `processed/csi300_alpha360_like_train.pkl`
- `processed/csi300_alpha360_like_valid.pkl`
- `processed/csi300_alpha360_like_test.pkl`
- `processed/sp500_alpha360_like_train.pkl`
- `processed/sp500_alpha360_like_valid.pkl`
- `processed/sp500_alpha360_like_test.pkl`

The processed files are not included because raw market data may be subject to redistribution restrictions.
